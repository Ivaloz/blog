# Homelab 入门指南

Homelab 是在家中搭建的个人服务器环境，用于学习、实验和自托管各种服务。

## 硬件选择

- **入门**: 旧电脑/NUC/树莓派
- **进阶**: Mini PC/二手服务器
- **存储**: NAS/硬盘柜

## 常用服务

- **容器**: Docker + Portainer
- **虚拟化**: Proxmox VE
- **网络**: Tailscale/ZeroTier
- **存储**: TrueNAS/OpenMediaVault
- **监控**: Grafana + Prometheus

## 注意事项

- 电费成本
- 噪音控制
- 散热方案
- 网络安全
