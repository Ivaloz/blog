# Copilot CLI 使用体验

GitHub Copilot CLI 是一个终端中的 AI 助手，可以直接在命令行完成各种开发任务。

## 核心能力

- 代码编写和修改
- 文件搜索和分析
- Shell 命令执行
- Git 操作
- 项目理解和重构

## 使用场景

- 快速原型开发
- 代码审查
- 问题排查
- 文档生成
- 项目脚手架

## 体验

响应速度快，理解上下文能力强，是开发效率的好帮手。
