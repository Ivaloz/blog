# Hello World — 博客上线

博客正式上线了！

## 技术栈

- **框架**: VitePress
- **部署**: GitHub Pages
- **域名**: ivalo.eu.org（EU.org 免费域名）
- **CDN**: Cloudflare（免费计划）
- **CI/CD**: GitHub Actions 自动部署

## 为什么选 VitePress

- 基于 Vue + Vite，构建速度极快
- Markdown 驱动，专注写作
- 内置搜索、RSS、SEO 优化
- 主题美观，开箱即用
