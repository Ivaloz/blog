## 🛑 诚实声明（必读，每次下注前回看）

1. **长期负期望**：竞彩足球返奖率约 65–75%（按玩法不同），剩下的是体彩的抽水。这意味着**长期平均必亏**。本线的全部价值，是用结构化分析在**个别场次**找相对价值点，把负期望尽量压小、偶尔吃到错盘——**不是稳赚，更不是印钞机**。
2. **量力而行**：设单场 / 单周预算上限，亏到上限就停。不上头、不追注、不借钱、不动用求职/生活资金。
3. **实时数据以你所见为准**：2026 的赛果 / 伤停 / 盘口都在 AI 知识截止（2026-01）之后。AI **不编实时数据**；凡标「需临场刷新」的，以体彩官方 + 你下注前亲眼所见为准。
4. **串关是抽水放大器**：越串，负期望被乘方放大。本线默认**单关 / 小串为主**，不鼓励大波串。

## 每场工作流（4 步）

1. **拿结构读数**（赛前已算好）：看 `2026-r32-foundation` + 对应 card 的「结构变量」段——④⑦⑧⑤⑥⑨ 都是赛前定死的，AI 已给判断。
2. **临场刷新**（你做，下注前 1–2 小时）：card 里有 ①②③ 刷新清单——查首发 / 伤停停赛、查最新盘口和异动方向。
3. **合判**：card 的「推荐倾向 + 玩法」是基于结构读数的；用第 2 步的临场信息修正或否决它。
4. **自主决定**：下不下、下哪个玩法、下多少。AI 给倾向，**钱是你的，最终你拍板**。

## 核心方法论（一句话）

> **④风格 + ⑦淘汰赛保守度 + ⑧场地** → 定**让球盘和总进球**（历史数据的主战场）；
> **①伤停 + ②本届势头 + ③盘口异动** → 每场刷新，定**胜平负和价值**；
> **⑩ xG / 射门质量** → 全局校准器，防止被「加拿大 90 分钟爆射」这种偶然结果带偏。
