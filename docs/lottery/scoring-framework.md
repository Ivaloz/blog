## 一、变量三分类（大方原创框架）

| 类别 | 维度 | 主要影响的玩法 | 何时定 |
|------|------|---------------|--------|
| **即时变量**<br>（每场必刷新） | ① 可用阵容 / 伤停 / 红黄牌停赛 / 临场体能 | 胜平负 + 总进球 + 比分 | 赛前 1–2h |
| | ② 临场状态 / 势头（**本届真实轨迹，非历史底蕴**） | 胜平负 | 滚动 |
| | ③ 官方盘口 + 盘口异动 / 资金流向 | **价值识别（全部玩法）** | 赛前滚动 |
| **结构变量**<br>（赛前定死） | ④ 战术风格匹配（控球vs防反 / 高压vs铁桶） | **让球 + 总进球（最关键）** | 赛前 |
| | ⑤ 交手历史（近期权重高，含心理） | 胜平负 + 心理修正 | 赛前 |
| | ⑥ 阵容深度 / 板凳（末段改变 90 分钟） | 胜平负 + 比分 | 赛前 |
| **情境变量**<br>（赛前定 / 半定） | ⑦ 90 分钟规则交互（淘汰赛保守度 / 摆点球意愿） | **「平」价值 + 让球** | 赛前 |
| | ⑧ 主场 / 海拔 / 天气（Azteca 2240m / 美国夏季高温） | **总进球 + 胜平负** | 赛前 |
| | ⑨ 动机 / 叙事 / 场外（谢幕战 / 魔咒 / 黑马放手一搏） | 无形项 / 平手分胜负 | 赛前 |
| **校验层** | ⑩ 底层数据 vs 结果（xG / 射门质量） | **校准上面全部判断** | 赛前 |

**核心分工**（大方定的）：
- **④⑦⑧ 决定让球盘和总进球** ← 历史数据最该往这里使（它们赛前定死、可提前算）。
- **①②③ 是动态的、每场必须刷新** ← 决定胜平负和价值识别。
- **⑩ 防止被偶然结果带偏** ← 校准器，最后一道闸。

## 二、变量 → 玩法 映射（怎么把每个变量翻成下注动作）

| 变量 | 读到什么 → 下注含义 |
|------|--------------------|
| ④ 风格匹配 | 控球队 vs 铁桶队 → 让球盘**难打穿**（让 -1 风险高）、**总进球偏小**；两支对攻队 → 总进球偏大、让球波动大 |
| ⑤ 交手历史 | 一方对另一方有近期心理优势 → 胜平负倾向 + 别被「纸面实力」误导 |
| ⑥ 阵容深度 | 板凳强 → 70 分钟后可能拉开 → 让球盘 / 大球在**末段**兑现（呼应补时绝杀）；板凳弱 → 越拖越守得住平 |
| ⑦ 淘汰赛保守度 | 两队都保守 / 善打点球 → **「平」被系统性低估**（竞彩按 90 分钟计奖，见下）→ 买平、买小球、让球盘选平半内 |
| ⑧ 场地 | 高原（Azteca 2240m）→ 体能消耗大、节奏可能两极；高温（美国夏季）→ 拖慢节奏、末段掉速 → **总进球偏小 + 耐热队占优**；圆顶/温和场 → 中性 |
| ⑨ 动机叙事 | 谢幕战 / 黑马放手一搏 / 魔咒 → 给「平」或冷门加权重，但只作微调，不主导 |
| ① 伤停 | 核心后卫停 → 失球概率↑（大球 / 让球）；核心前锋伤 → 进球↓（小球）；门将 / 关键中场缺 → 强弱逆转 |
| ② 本届势头 | 本届真在状态的队 ≠ 历史豪门；**用本届轨迹覆盖历史底蕴** |
| ③ 盘口异动 | 开盘到临场盘口往哪走 + 资金往哪流 → **最硬的价值信号**；你的判断 vs 实际开盘的差，就是潜在 edge |
| ⑩ xG | 结果是真实力还是运气？高 xG 输球的队被低估、靠运气赢球的队被高估 → 反向修正 ②③ |

## 三、🔑 ⑦ × 竞彩计奖 = 本系统最该吃的「平」金矿

**规则事实**：竞彩足球绝大多数玩法（胜平负 / 让球 / 比分 / 总进球 / 半全场）**只按 90 分钟 + 伤停补时**计奖，**不含加时和点球大战**。

**推论**：淘汰赛里，一支「90 分钟踢平、靠点球晋级」的强队——在竞彩里算**「平」**，不算赢。

**所以**：
- 当 ⑦ 信号强（两队都保守 / 一方明显摆铁桶求点球 / 历史爱拖进加时，如克罗地亚），**「平」的真实概率被大众和盘口低估**——因为大众下意识买「强队晋级」，但晋级 ≠ 90 分钟赢。
- **吃法**：① 直接买「平」（胜平负）；② 让球盘选「平半 / 平」一侧；③ 配合 ⑧ 高温 / ④ 铁桶 买**小球**。
- **典型场次**：强弱差距没那么大、或弱队铁桶 + 善打点球的淘汰赛对决。

> 这是整套系统里**最稳的结构性偏差来源**——不依赖预测谁赢，只依赖「90 分钟分不出胜负」的概率被低估。

## 四、⑩ 校准器：别被偶然结果带偏

**原则**：一场比赛的**结果**（比分）是**样本量=1 的随机变量**；**xG / 射门质量 / 控场**才是更接近真实力的信号。

**本届现成案例**：
- **加拿大 R32 1-0 南非**，第 90 分钟禁区外凌空抽射绝杀。**别据此把加拿大下一场捧上天**——那一脚是低概率事件。但也**别全盘否定**：加拿大小组赛进 8 球（GD+5），攻击力是真的。**结论：看 xG 和过程，不看那一个进球。**

**操作**：每次根据「某队上一场赢/输」调整判断前，问一句——**那个结果是 xG 支撑的，还是运气？** 是运气就打折。
